# Post-hoc Gemini comparison on Thai final reports

The 2026-09-27 saved answers compare Thai BM25 passages + Gemini and the normal online app agent + Gemini on the same public SCBX and Thai Union 2567 selectable-text corpus as the frozen offline test. This was added **after** seeing the offline scores and is supplemental, not an untouched final test. No cloud OCR ran. `metrics.json` includes exact answer scores, timings, and Vertex token usage. BM25 + Gemini scored 6/20 strict answers; app Gemini scored 2/20. The [post-run audit](postrun_audit.md) records a scorer false negative on TF10 without altering the saved score. The original PDFs, embedding vectors, and temporary database are excluded. See `../heldout_thai_gemini_supplement_method_v1.json` for the script and scoring file hashes.
