## ข้อจำกัดที่คงไว้ในรายงาน

- F10 ยังคงไม่ผ่านจากค่าประกอบ USD ที่ไม่อยู่ใน label ที่อนุญาต
- F05 มีหน้าเป้าหมายใน sources แต่เลขหน้าในข้อความตอบไม่ตรง จึงยังต้องปรับ citation scorer
- L11 ยังมี OCR ผิดเลข และ reference ยังต้องตรวจต้นฉบับซ้ำ
- เฉลยยังไม่มี independent human certification
- Local network block เป็น process-level และยังตอบคำถามจริงที่ลองไม่ผ่าน
- การ OCR 220 หน้ากับการหยุดแล้วทำต่อยังไม่เท่ากับ full upload/index/Q&A workflow
- คะแนน branch เดิม 474/499 แยกจากคะแนนปัจจุบันอย่างชัดเจน
