ผลล่าสุดของ PTT/PTTEP คือพบหน้าครบ 16/16 และคำตอบผ่านเกณฑ์พร้อมมีหน้าใน sources 15/16 ชุดนี้ถูกใช้ปรับระบบแล้ว และมีหลักฐานกระจุกบน 3 หน้า ไม่ใช่ final held-out test ผล 95.0% ของ branch เดิมแยกไว้เป็นประวัติ ไม่ใช่คะแนนปัจจุบัน
